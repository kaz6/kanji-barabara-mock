# N4_TABLES（KJ-006）

N4 で足した 割り方・対義・巡り の一覧。作者が赤を入れるためのもの。どれも仮置き（R-038〜R-041）。
直すときは data/parts.json・antonyms.json・cycles.json を直して `npm test` を回す。

- 割り方は「見て分かる形」（字の成り立ちではない）。[左（上）, 右（下）] の順で、くっつけるはこの順に並べたときだけ成り立つ
- （部品）＝常用漢字の外の形。部品の色で見せる。（中継ぎ）＝N4 の字ではないが、さらに割れる字（2回くっつける形）
- 水・手・牛・金・糸 は左に置いたとき 氵・扌・牜・釒・糹 の形で見せる（札はもとの字）。心（忄）は左に来る字がないので足していない
- 印 ？ ＝迷ったもの（形を少し落としている・代わりの字を使っている）
- N5 で遊ぶときは、N4 の字の行と、N4 にしか使わない中継ぎは使わない

|---|---|---|---|---|
| 玉 | 王 | 丶（部品） | ？ | 国→玉→王 と割れる（国＝囗＋玉）。丶 は右下の点。主（丶＋王）とは並びの順が逆で、Join は 王丶＝玉・丶王＝主。N5 でも 王 が手に持てる字になり、語が29語 N4→N5 |
| 足 | 口 | 止 | ？ | 上下。止 を parts.json の jouyou に足した（N5 の字の割り方に出る N4 の字は jouyou に入れる習わし）。N5・小1 でも 止 が字になり、中止・休止・小休止・雨天中止 など9語（N5）が N4→N5。N4 は動かない |
