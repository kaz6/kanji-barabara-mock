# STRINGS（画面の文言の一覧。KJ-024）

作者が赤を入れる一覧。正本は `js/strings.js`（画面はそこから出す）。DECISION_LOG は R-056（D-041）。

英語にしたのは操作の8つのボタンの文字と、札の角の印だけ。ほかの画面の文言（はじめる前・場・手札・ストック・台の行・はじかれた理由・終わり・しくみ）とログは日本語のまま。

## ボタン

| 日本語の元の文言 | 英語 | 決めた人 |
|---|---|---|
| 放つ | Play | 作者（「あとは提案通りで」） |
| 割る | Split | 作者 |
| くっつける | Join | 作者（同上） |
| 反転 | ⇄ Flip | 作者（同上。アイコンも作者） |
| 巡り | ↻ Cycle | 作者（同上。アイコンも作者） |
| 同音 | ♪ Sound conversion | 作者（「Sound conversion にしよう」。アイコンも作者） |
| 戻す | Back | 作者（同上） |
| 引き直し | Redraw | 作者（同上） |

## ボタンの添え字

| 日本語の元の文言 | 英語 | 決めた人 |
|---|---|---|
| 5点（点があるとき） | 5pt（Redraw 5pt） | 相談チャット（作者「あとは提案通りで」） |
| 30秒（点がないとき） | 30s（Redraw 30s） | 相談チャット（同上） |
| 待ち 12s（引き直しを待っているあいだ） | wait 12s（Redraw wait 12s） | 係の仮決め |
| 反転・巡り・同音の待ち 3s など | 3s（今まで通り） | 変えていない |

## 札の角の印

| 日本語の元の文言 | アイコン | 決めた人 |
|---|---|---|
| 反 | ⇄ | 作者 |
| 巡 | ↻ | 作者 |
| 音 | ♪ | 作者 |

- 並びは今まで通り 反→巡→音 の順（例：反音 → ⇄♪、巡音 → ↻♪）
- しくみの説明の「（印：反）」なども「（印：⇄）」にした（説明の文は日本語のまま。係の仮決め）
