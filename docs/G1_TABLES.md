# G1_TABLES（KJ-044）

レベル「小1」（小学1年で習う漢字80字。KANJIDIC2 の grade=1）の字の一覧と、割り方の足し方。作者が赤を入れるためのもの。どれも仮置き。
直すときは data/parts.json・split_shapes.json を直して `python3 tools/build_data.py`（語を作り直す）→ `npm test`。

- 小1 の字は、N5・N4 と重なる（80字のうち N5 が57字・N4 が15字）。N5・N4 のどちらにも無い8字（石・竹・王・玉・草・虫・糸・貝）は、データでは lv＝G1 の行（小1 のときだけ山に入る）。ほかの72字は、もとの lv（N5／N4）のまま g1:true が付く
- 小1 で遊ぶときの山（と最初の手札）は、この80字だけ。放てる言葉は今まで通りレベルで縛らず、手に持てる字（80字＋割る・くっつけるで出る字＋巡り・対義・同音で行ける字）で書ける語（1字・2字・3字・4字・四字熟語）
- 割り方（parts.json）の足し方：**N5・N4 の字に足すと、N5・N4 で遊ぶときにも割れるようになり、手に持てる字と放てる言葉が動く**ので、今回は N5・N4 に無い字（lv＝G1 の字）にだけ足した。N5・N4 の字で割れそうなものは下の「割れる候補」に書いた（足していない。足すなら作者が決める）
- 玉＝王＋丶 は足していない（受け箱 P-047 で足す。国→玉→王 と割れて、N5 の語が動くため）
- 巡り・対義は今のまま。小1 で回るのは 曜日（月火水木金土日）と 数（一〜十）だけ。方角・四季・十二支は、その字が80字にそろわない（東・春・午 などが無い）ので小1 では回らない（N5・N4 では今まで通り）
- 印 ？ ＝迷ったもの

割れないまま残した字（N5・N4 のどちらにも無い小1 の字）：竹（个が2つで、見て分かる2つに割れない）・虫（口＋中 の形が崩れる）・王（一＋土 と割れるが、玉＝王＋丶 の P-047 と合わせて決める）・玉（P-047 で足す）。貝 はもとから 目＋八 で割れる。

## 割れる候補（足していない：N5・N4 の字なので、足すと N5・N4 の遊びが動く）

| 字 | 候補 | メモ |
|---|---|---|
| 足 | 口＋止 | 上下。見て分かる形。足すと 口・止 が手に持てる字になり、語が増える |
| 赤 | 土＋小（に近い形） | ？ 下の形が 小 とは少しちがう |

ほかの小1の字（年・手・立・先・気・車・耳・雨・夕・円・文・力・川・女・金 など）は、見て分かる2つに割れない、または部品の形が崩れるので候補に入れていない。
