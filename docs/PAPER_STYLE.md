# 新聞紙風の見た目（KJ-093。受け箱 P-093）

作者（2026-11-25）：「見た目も俺好みの大正風フォントで新聞紙風の見た目にしようかなーあと思ってる」「21いいですね。」「札の字、大正風と、切り替えられるようにしてほしい」「題字は表紙に回します〜」「案入れてみよう」（表紙に号数と日付）

見本：デザインのキャンバスの「新聞21」（試合の画面）・「新聞10」（札が大正風）・「表紙2」（号数と日付の行）。置き場は実機のまま、色・字体・線だけ真似た。

## 字体（同梱。`tools/build_paper_fonts.py`）

- 画面の字（ボタン・点・見出し・説明）：Zen Old Mincho 400・700（`fonts/kj-zen-*.woff2`。1009字）
- 札の字：大正風＝Kaisei Tokumin 400（`fonts/kj-kaisei-400.woff2`。746字）／明朝＝Shippori Mincho 400（`fonts/kj-shippori-400.woff2`。778字）
- 3つとも SIL OFL 1.1。本文は `fonts/OFL-Paper.txt`、画面の「しくみ」にも載せた。`fonts/kj-paper.css` が @font-face（`unicode-range` つき）
- 同梱にした理由：Google Fonts の CSS を読むと、日本語の字体は分割ファイルが 100 本以上で、表紙を開くたびに外へ取りに行く。ここでは要る字（data/*.json に出る字と、画面の文）だけに絞って合わせ、4本で約 700KB（woff2）。外に出ずに、オフラインでも同じ見た目。足りない字は `python3 tools/build_paper_fonts.py`（元の字体は `npm pack @fontsource/zen-old-mincho` ほかで取る。使い方は先頭の説明）で作り直す
- 札の字の落とし先：大正風＝Kaisei → Shippori → kj-glyphs → 端末の明朝／明朝＝Shippori → Kaisei → kj-glyphs → 端末の明朝。切り替えは設定「札の字」（`<html data-face>`・localStorage `kj-face`。初期は大正風）。特別な語の演出（kj-fx）は変えない

### 札の字で字体が替わる字（形がちぐはぐになるもの）

- 大正風（Kaisei）に無く、Shippori Mincho で出る33字（部品の札が多い）：丂 丷 亍 亻 亼 关 刂 另 圣 开 扌 斦 氐 氵 灬 牜 疒 礻 糹 罒 翟 耂 艹 虽 訁 辶 阝 飠 𠂉 𠆢 𠬝 𡗗 𦰩
- どちらにも無く、kj-glyphs（同梱の字体）で出る12字：⺌ ⺍ 产 亲 兑 刍 吅 电 釒 龶 龺 𢀖
- 明朝（Shippori）に無く Kaisei で出る札の字は無い

## 罫線・形

- 卓の上下は太い罫線（3px 墨）。卓の左に縦書きの見出し「卓　場と台」（`.table::before`。押せない・読み上げない飾り）。この分、卓の中は左が 26〜28px 狭い（375px で支障なし。320px の手札の8枚目が右へ出るのは前からで、変えていない）
- 操作5つ（Split・Join・Flip・Cycle・Same reading）は、罫線で仕切った一続きの段。Play は弁柄の地に紙色の字。押せない Play は暗い弁柄（前の色）
- 選んだ札は弁柄の縁（2px）・地は札の色のまま・字は墨。割れ目の点線は選んだ札でも茶色のまま（前は赤地の上で白）
- 角丸はやめた（札・ボタン・卓・台・パネル・チュートリアルの枠・🚫 の箱・演出の札）。光の輪（点の演出）は丸のまま
- 終わりの画面・チュートリアル・ヒントの光り・🚫・食らいの演出・台の行は、色と字体だけ合わせた

## 表紙

- いちばん上に題字「バラバラ新報」（仮の名。`js/strings.js` の `TEXT.masthead` 1か所）。二重罫線で挟む。題字の後ろの絵柄は下の「表紙の絵柄」（KJ-095）
- すぐ下の行：左「第○號」（○＝その端末で始めた試合の数＋1。漢数字。localStorage `kj-issue`。読めなければ 第一號）・中「今日の日付」（例 二〇二六年十一月二十五日）。行の下に二重罫線
- 号数は、CPU 対戦の「はじめる」「もう一度」と、合言葉の部屋で試合が始まったときに増える。チュートリアルは数えない
- 漢数字・号数・日付は `js/core.js` の `K.kansuji`・`K.issueLabel`・`K.kansujiDate`（DOM に触らない）
- 試合の画面には題字を出さない

## 戦況の欄・背景の記事・紙のざらつき（KJ-094。受け箱 P-094）

作者：「戦況は読まないけど賑やかしにいいので好きです」「背景にうすく新聞ぽい長文を羅列する」「戦況で使われるひらがなに相当する箇所はカタカナにしたい。読めたらすごいよってことで」「ルール書いたの天才。不透明度20くらいにできる？」「これくらいがすきですね。」（見本：新聞21・新聞17）

- 戦況：前の「放った言葉」の欄を替えた。左に墨の地の縦書きの見出し「戦況」、中は縦書き。放った言葉を新しい順（右が新しい）に、漢字カタカナ交じりの文で。「アナタ、空白（クウハク）ヲ放ツ。二字ニテ三点。場ヨリ新・話ヲ取ル。」。あなたの行は弁柄の太字。放った言葉そのものは漢字のまま（札の字）。入りきらない古い行は欄の左の外へ流れる
- 文の型は `js/strings.js` の `SENKYO`（仮）。組むのは `js/core.js` の `K.senkyoLines(log, {me, tpl, kana})`（DOM に触らない。あなた→アナタ。場から取った字は、その人のその放ちのあとの 取る を並べる。取るたびに文のおわりが増える）。画面は index.html の `renderReleased`
- 欄の高さ：空のあいだは 34px（前の見出しと同じ。375×700 に収める決まり＝KJ-010 を守るため）・1つ放ったら 150px（`--sk-h`）
- 背景の記事：`#bgnews`。画面いっぱい（position:fixed）・縦書き 10px・墨の不透明度 20%・main より下の層（札・ボタンの下に隠れる）・押せない（pointer-events:none）・読み上げない。文は `js/strings.js` の `NEWS`（仮）を、画面が埋まるぶん（上限 200 回）繰り返す。卓の地を透かした（`.table` の背景を透明に。下は同じ紙の色）。ストックなどの空きマス（点線）は紙の色を濃く敷いて（`--slot-fill`）記事が透けないようにした
- 設定「背景の記事：入／切」（初期は入。localStorage `kj-news`。切＝`0`。`<html data-news="off">` で記事だけ消える。ざらつきは残る）
- 紙のざらつき：見本の feTurbulence（粒 baseFrequency 0.9・繊維 0.012 0.09）を SVG の小さな敷き紙（160px・320px。継ぎ目なし）にして body の背景に重ねた。タイルは1回だけ描いて使い回す。固定の背景にはしていない

## 補足（レビューのあと）

- 札の字の切り替えは、前から `--kanji` を使っていた所（終わりの画面の語・ログの語・選ぶ札・点の演出の札）にも効く（カードの「効く所」より広い）
- 表紙は題字の下に前の題「漢字版（仮）」と説明文が残る（カードに消す指示が無いので、作者に聞く）
- 押せない文字は `--dim`（#625a50）に濃くした（紙の上で 4.5 以上）。取ったばかりの札・ヒントで光る札を選んでも、縁は弁柄
