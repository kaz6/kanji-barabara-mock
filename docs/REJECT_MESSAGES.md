# はじかれたときの理由の言い方（KJ-022・D-040）

はじかれたとき（放つ・くっつける・割る・反転・巡り・同音・取る・引き直し）は、画面の真ん中に大きく 🚫 と短い理由を 1.5 秒出す（音なし。次のはじかれで出し直し）。
決まりの側の理由（ログの「ためした」のメモ）は今のまま。出すときだけ `K.rejectText`（js/core.js）で言い切りの形にする。作者が赤を入れる。

- 表にあるもの（言い換える）：下の表
- 表に無い短い理由（16字以内）：そのまま ＋「！」（例：割れない → 割れない！、待ち時間 → 待ち時間！）
- 長い文・「！」「。」「？」「…」で終わるもの（チュートリアルの案内など）：そのまま

| 決まりの側の理由（ログ） | 画面に出す |
|---|---|
| 〇円は一度きり（使った助数詞が 円 のとき。人・本・日…も同じ形） | 〇円は一度きり！ |
| 1字では放てない（2字以上の言葉） | 2字から！ |
| かなだけでは放てない（漢字の札が1枚以上いる） | 漢字の札が要る！ |
| 放った言葉 | もう放った言葉！ |
| 並べる順が逆 | 順番が逆！ |
| 辞書にない | 辞書にない！ |
| 手札もストックもいっぱい | 手札もストックもいっぱい！ |
| 手札がいっぱい / ストックがいっぱい | 手札がいっぱい！ / ストックがいっぱい！ |
| くっつかない | くっつかない！ |
| 割れない | 割れない！ |
| できない字 | できない字！ |
| 待ち時間 | 待ち時間！ |
| 同じ読みの字がない | 同じ読みの字がない！ |
| 取れる枚数がない | 取れる枚数がない！ |
| 相手が先に放った / 相手が先に取った | 相手が先に放った！ / 相手が先に取った！ |
| 引き直しは5回まで | 引き直しは5回まで！ |

？（自信が無い）：「手札もストックもいっぱい！」は、card の例の「手札がいっぱい！」と少し違う（ストックも満杯のときの理由なので、決まりの側の言い方のまま）。
