# RADICAL_MEANINGS（KJ-021）

部品の札（字として見せない札）が、何と同じ意味かの一覧。台に部品の札を置く・手札で選ぶと、台の行に出る。作者が赤を入れるためのもの。どれも仮置き。
直すときは `data/radical_meanings.json` を直す（この一覧は手で合わせる。tests/radical.test.js が、部品がこの一覧に全部あるかを見る）。

- 出典：呼び名は KANJIDIC2（jamdict の部首名）と一般の呼び方。意味は部首の一般的な意味から。自信の無いものに ？
- 台の行の出し方：`亻（にんべん）＝人`（同じ意味の字があるとき）／`艹（くさかんむり）草のこと`（無いとき）／呼び名の無い部品は `云＝言` `亲 新・親 の左がわの形`
- 部品の数：78（？ は 46）
