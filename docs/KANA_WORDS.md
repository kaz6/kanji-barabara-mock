# かなの語（KJ-053・D-069）

部品の札 ノ・儿・ナ を、台に並べたとき かな の・る・な として言葉に入れる。かなは1字に数える（見る＝2字3点、天の川＝3字9点）。部品だけ（かなだけ）の並びは放てない。tools/build_data.py が JMdict から作る（手で直さない。外したい語は data/blocked_words.json か data/blocked_words_g1.json へ。外すのは作者だけ）。

- 入れる語：2〜4字。かなが ちょうど1つ（の・る・な）で、先頭でない。ほかの字はそのレベルで手に持てる字。かなの部品がそのレベルの割り方の行に出てくる
- 入れない語（迷ったら。仮）：かなを2つ以上含む語 17 語・かなで始まる語 1 語（下に一覧）
- 印：★＝よく使う（CPU が知っている語。ヒントでも先に狙う）・小1＝小1 でも放てる
