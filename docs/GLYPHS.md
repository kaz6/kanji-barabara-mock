# GLYPHS（札の字がスマホで出るか。KJ-027・D-042）

作者が赤を入れる一覧。`python3 tools/build_glyphs.py` で作り直す（このファイルも data/glyphs.json も fonts/kj-glyphs.otf もここから出る）。

## 調べ方（仮決め）

- 対象：data の札の字ぜんぶ（字・割る前の字・割ってできる部品・中継ぎ・巡りの字〔曜日・四季・十二支など〕・偏の形）。440 字
- 「出る」＝JIS X 0208 の中の字。日本の端末（iOS の ヒラギノ・Android の Noto CJK JP など）の標準字体に必ずある。395 字
- 「同梱」＝JIS X 0208 の外の字。JIS X 0213 だけの字（亻・氵・艹 など）・部首補助（⺌ ⺍）・簡体字の形（电・产 など）・拡張B（𠂉 など）。端末によって出ない・中国の字形になるので、字形を同梱して必ず出す。45 字
- 同梱のしかた：Noto Serif CJK JP（明朝。画面の字体を明朝にそろえるため。SIL OFL 1.1。本文は fonts/OFL.txt）から必要な字の字形だけ取り、`fonts/kj-glyphs.otf`（名前は KJ Glyphs）にした。画面は、この字のときだけこの字体を先に使う（`@font-face` の unicode-range）。字は文字のまま（選んでコピー・ログは今までどおり）
- フォントに無い字（𢀖）は、フォントの字形 幺 と 夂 を重ねて作った（後 の右側）
