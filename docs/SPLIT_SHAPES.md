# SPLIT_SHAPES（KJ-014）

割れる札に出す点線の一覧。作者が赤を入れるためのもの。どれも仮置き（R-049）。
直すときは data/split_shapes.json を直して `npm test` を回す。割り方（parts.json）は変えていない。

- 形：左右＝縦の点線／上下＝横の点線／その他＝点線の代わりに角に「割」（囲み・それ以外）
- 線の位置：左右は左から、上下は上から、字の幅（高さ）に対するおおよその割合（0〜1）。例：休 は左の 亻 が細いので 0.3
- 印 ？ ＝迷ったもの（形か位置）。位置 0.5 の字は、本当にほぼ真ん中のもの（真ん中で済ませたのではなく、字ごとに見て決めた）
- 囲みの字には外側の部品（out）を持たせた（KJ-017）。引きずって相手の札の「中央」に落とすくっつけ方に使う。「それ以外」（辶・广 など）は面ではくっつけない
- 点線は字に重なってよい。角の印（反・巡・音＝右上、選んだ順＝左上、元の字＝左下）に重ならないよう、その札だけ線を短くする
