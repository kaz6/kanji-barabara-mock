# PROPER_NAMES（言葉として通す地名・名字の一覧。KJ-032）

作者が赤を入れる一覧。正本は `data/proper_names.json`（words.json は `python3 tools/build_data.py` で作り直す）。DECISION_LOG は R-078（D-047・D-048）。

- 作者の言葉：「人名、地名も代表的なものは可能にしようかな」「試験もそうだけど、覚えることがだいじな気がしていて」
- 通すのは、手に持てる字だけで書ける 2〜4字 のときだけ（D-029）。点数は普通の言葉と同じ。台の行に〔地名〕〔名字〕の印
- 下の名前は入れない。1字の名字・市（林・森・原・津・堺）は放てない（1字は放てない）ので語には入れない
- 「県」「府」「都」「市」を付けない形で入れた（係の仮決め）。付いた形（青森県・東京都・水戸市 など）は JMnedict に地名として載っていれば通す
- 読みは JMnedict（EDRDG）と突き合わせた（全部の行で、その読みが地名・名字として載っている）
- 名字の出典：森岡浩「日本人の名字ランキング」上位100（https://office-morioka.com/myoji/best200.html 、2016年4月時点）。新旧字体の違いは新字体の1つ（渡辺・斎藤・斉藤・桜井・浜田）。出典は読みをまとめて数えている
- 辞書（JMdict）にもとからあって読みが違う語は、台の行に両方を並べる（大分 だいぶ／おおいた〔地名〕・三重 さんじゅう／みえ・金子 きんす／かねこ・上田 じょうでん／うえだ・山下 やまもと／やました・高木 こうぼく／たかぎ・上野 こうずけ／うえの）。意味（英語）はもとの語のまま
- ？：読みが2つ以上ある名字（代表を1つにした）。作者が確かめる
- 「放てるレベル」が — のものは、いまはどのレベルでも手に持てない字を含むので放てない（大阪 の 阪、佐藤 の 佐・藤 など）
